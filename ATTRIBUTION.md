# ATTRIBUTION

## Code

Écrit pour le Meetup Fastai-FR « Quand l'IA réinvente ses propres mathématiques :
la révolution du 9/4 ». Licence MIT pour le code produit ici.

## Idées et résultats

| Élément | Source |
|---|---|
| Borne supérieure ω ≤ 9/4 (2 oct. 2026) | OpenAI, dépôt public `openai/math` |
| Borne inférieure ω = 9/4 (24 nov. 2026) | OpenAI, dépôt public `openai/math` — **non vérifié par les pairs** |
| Formalisation Lean partielle | `openai/math/lean` (théorème `square_exponent`) |
| Algorithme de Strassen (1969) | Strassen, *Gaussian elimination is not optimal*, Numer. Math. 13 |
| Rang 7 du tenseur 2×2 | Winograd (1971) ; Landsberg, *Geometry and Complexity Theory* |
| AlphaTensor (2022) | DeepMind, Nature 610, 47–53 ; code public `google-deepmind/alphatensor` |
| AlphaEvolve (2025) | DeepMind, agent de programmation évolutionnaire |
| GPT-2 small | OpenAI, poids publics via Hugging Face |

## Ce qui n'est pas de nous

- Les poids de GPT-2 (licence MIT, OpenAI).
- Les décompositions d'AlphaTensor citées en démonstration (DeepMind).
- Les deux manuscrits d'OpenAI : cités, résumés, jamais reproduits en intégralité.

## Honnêteté intellectuelle

Le kit présente les résultats de novembre 2026 comme des **revendications en cours de
vérification**. Aucune reproduction indépendante n'était publique au 25 novembre 2026.
Le code de ce dépôt vérifie des faits mathématiques élémentaires (Strassen, rang du
tenseur 2×2, ordres de grandeur) — **il ne vérifie pas** les preuves d'OpenAI, et ne
prétend pas le faire.
